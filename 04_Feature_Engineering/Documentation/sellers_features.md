**1. seller\_city\_state**



Description:

Represents the seller's city and state combined into a single geographic identifier.



Business Purpose:

Simplifies geographic analysis, reporting, filtering, and dashboard visualizations involving seller locations.



Formula:

seller\_city + ", " + seller\_state



Source Column(s):

seller\_city

seller\_state



Data Type:

object



Expected Values:

City, State



Missing Values:

None



Example:

campinas, SP
